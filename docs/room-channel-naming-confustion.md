# Room/Channel naming confusion

Manchmal nutze ich den Begriff Room und manchmal Channel.

Dinge die es gibt:

- room: Chatraum in dem Messages sind
- channel: spezieller Typ von room der ein chatraum im server ist
- dm: ein spezieller Typ von room der ein privater chatraum zwischen zwei Nutzern ist
- voice room: ein konzept von livekit. das ist ein instanz eines sprachanrufs.
